# KeyOops 0.2.0 beta 2

Download **KeyOops-build-3-macOS-universal.dmg**, quit the previous version, and drag KeyOops to Applications. The ad-hoc signed build targets macOS 14 or later on Intel and Apple silicon. macOS may ask you to approve the updated app or grant its permissions again. [First-launch instructions and compatibility checklist](0.2.0-beta.1.md)

Live corrections now verify that the host applied the requested text before switching layouts. A failed write preserves a newer user selection. Continuing to type dismisses a pending correction. AppKit regression checks exercise these paths with a native text view, including undo after a word preceded by an emoji.

## Detector check

Measured with ABC and Russian enabled, using distinct isolated tokens from the four attributed English and Russian lists. Run `swift run VerifyLayouts` to reproduce. Each row describes the intended language.

Beta 1 suggested 26 of the Russian-language cases and missed 35. Recognizing punctuation keys such as the comma in `,skj` (было) adds 17 suggestions. Automatic edits use the existing thresholds. These fixtures cover common words and overlap the detector's vocabulary. They do not measure performance on independent natural typing or confirm host-specific behavior.

Live support remains scoped to TextEdit and Notes. Permission transitions and editing in those actual applications still need interactive acceptance testing.
