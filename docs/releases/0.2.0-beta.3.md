# KeyOops 0.2.0 beta 3

Quit KeyOops, open **KeyOops-build-4-macOS-universal.dmg**, replace the app in Applications, and select the desired live mode after launching it. macOS may ask you to approve the updated app or its permissions. [First-launch instructions](0.2.0-beta.1.md)

## Try contextual correction

1. In TextEdit select ABC and choose **Suggest** in KeyOops.
2. Type `Pf,skf gthtrk.xbnm zpsr`, then press Space. Keep typing past any earlier suggestion. The menu should offer **Accept “Забыла переключить язык”**. The text changes only when you accept.
3. Type `z` and Space on a new line. It should remain `z`. Short words such as я or в can participate when subsequent words support a layout mistake.
4. For the other direction, select Russian and press the physical English keys for **I forgot language**, then Space. Check the proposed English phrase.
5. Repeat in **Automatic**. A sufficiently supported phrase can be applied before the end of the sentence, and the keyboard switches for subsequent typing. A competing dictionary reading such as `еру` for English **the** requires confirmation in a phrase.

## How the decision works

At Space the live detector looks back at most four adjacent tokens within 160 UTF-16 units. It compares the physical-key reconstruction with both local dictionaries, preserving case. A short function word can participate but cannot establish intent. A single longer word supporting a short one can produce a suggestion. Automatic phrase edits require two distinct longer words supporting the same layout and no flagged source-word collision. Single-word corrections retain their previous rules.

A change of script, an unsupported token, a line break or a double space ends the search. Dismissing or undoing a proposal limits subsequent lookback at that caret. Unknown phrases, rare names and ambiguous readings can still be missed. The mechanism uses local dictionary evidence and does not analyze grammar.

The reported sentence passes with the enabled macOS layouts. CI also checks simulated word-by-word typing in both directions, valid bilingual prefixes, URLs, variable names and stale previews. Interactive testing in each editor remains part of beta acceptance.
