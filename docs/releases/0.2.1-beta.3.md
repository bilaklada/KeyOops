# KeyOops 0.2.1 beta 3 (build 8)

Quit KeyOops, open **KeyOops-build-8-macOS-universal.dmg**, and drag KeyOops into Applications. Choose Replace and launch the installed copy. The app supports macOS 14 or later on Intel and Apple silicon.

This beta is ad-hoc signed and has no Apple notarization. See the [first-launch guide](https://github.com/bilaklada/KeyOops/blob/v0.2.1-beta.3/docs/releases/0.2.0-beta.1.md). Enable Accessibility and Input Monitoring for /Applications/KeyOops.app, then choose Suggest or Automatic in its menu.

## What changed

When an application returns incomplete accessibility information for a text field, KeyOops retries the individual attributes. If it still cannot verify the field, the menu identifies the failed check. Secure fields, recognized terminals and source editors remain excluded.

The live-edit regression checks passed. Live correction in the VS Code Codex prompt remains unverified because macOS denied the host verifier Accessibility access.
