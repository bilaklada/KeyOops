# KeyOops 0.2.0 beta 1

Download **KeyOops-build-2-macOS-universal.dmg** on a Mac running macOS 14 or later. Open it, drag KeyOops onto Applications and launch it from there. The installer contains both Intel and Apple silicon executable slices. Xcode is only needed to build from source.

This beta is ad-hoc signed. Gatekeeper may ask for approval on first launch. If you choose to trust this download, follow [Apple's instructions for opening an unnotarized app](https://support.apple.com/en-us/102445). Managed Macs may require administrator approval. The accompanying SHA-256 file can be checked from the download directory with `shasum -a 256 -c KeyOops-build-2-macOS-universal.dmg.sha256`.

Enable English and Russian layouts in System Settings. Select text and use **Services → Correct Keyboard Layout with KeyOops** in editors that offer the command. Live correction starts Off. Choose **Suggest** or **Automatic** from the KeyOops menu to try it in TextEdit or Notes. Live mode asks for Accessibility and Input Monitoring. After granting access, relaunch if macOS requests it and select the mode again.

## Acceptance checks for a stable release

- On a fresh install, exercise grant, deny and revoke flows for both permissions.
- In TextEdit and Notes, type `ghbdtn` and Space with ABC active. Check the corrected word and the change to Russian. Repeat in the opposite direction with `руддщ`.
- Accept and dismiss a suggestion, undo an automatic edit, switch windows before acceptance, and type while a suggestion is pending.
- Verify no live edits in password fields, terminals, unsupported editors or while secure input is active.
- Exercise the download and first launch on additional Intel and Apple silicon machines. CI covers compilation and deterministic tests on both architectures.

Report the application, macOS version and a synthetic example with each result. This preview does not claim Tilqos's detection benchmarks or its application coverage.
