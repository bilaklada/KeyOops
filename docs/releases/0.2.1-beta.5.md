# KeyOops 0.2.1 beta 5 (build 10)

Quit KeyOops, open **KeyOops-build-10-macOS-universal.dmg**, and drag KeyOops into Applications. Choose Replace and launch the installed copy. The app supports macOS 14 or later on Intel and Apple silicon.

This beta is ad-hoc signed and has no Apple notarization. See the [first-launch guide](https://github.com/bilaklada/KeyOops/blob/v0.2.1-beta.5/docs/releases/0.2.0-beta.1.md). Enable Accessibility and Input Monitoring for /Applications/KeyOops.app, then choose Suggest or Automatic in its menu.

## What changed

Choose **Copy corrected passage** in the KeyOops menu to copy the entire tracked suggestion, including unchanged words and spacing. Select the corresponding passage in your app and paste to replace it yourself.

For a verified field without readable text ranges or a caret, KeyOops can now suggest corrections from uninterrupted typing. The same contextual model can revise earlier words. These suggestions are preview-only. Secure inputs, excluded hosts and fields without verifiable ownership remain unavailable.

Contextual and live-edit regression tests passed. Live operation in Gmail and the VS Code Codex prompt remains unverified.
