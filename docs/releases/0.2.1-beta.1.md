# KeyOops 0.2.1 beta 1 (build 6)

Download **KeyOops-build-6-macOS-universal.dmg** for Intel or Apple silicon on macOS 14 or later. Quit any running copy of KeyOops, open the disk image, drag KeyOops into Applications, and choose Replace if prompted. Launch KeyOops from Applications.

This testing build is ad-hoc signed and has no Apple notarization. If macOS blocks first launch, follow the [first-launch guide](https://github.com/bilaklada/KeyOops/blob/v0.2.1-beta.1/docs/releases/0.2.0-beta.1.md). Grant Accessibility and Input Monitoring to /Applications/KeyOops.app in System Settings → Privacy & Security. Reopen KeyOops and choose Suggest or Automatic in its menu. Live mode starts Off.

## Try the beta

- In Suggest mode, type several words or sentences with the wrong keyboard layout. Tab accepts the accumulated correction and Esc dismisses it. Supported code editors and spreadsheets use Option–Space for acceptance.
- In Automatic mode, type the English keys for **here are some of the best classical poetry** starting on the Russian layout. Keep typing normally when KeyOops switches layouts. Confident corrections can include an earlier ambiguous word.
- Try an ordinary browser input, a multiline field, or an unsent message draft. Switch tabs before accepting a suggestion and check that the old suggestion disappears.

Cross-application editing is experimental. A field must expose enough accessibility information to verify the original text, caret, and document. The signed universal bundle and automated correction checks passed. End-to-end correction, isolation, undo, and visible preview latency in browsers, Mail, and Electron chat are still under test.
