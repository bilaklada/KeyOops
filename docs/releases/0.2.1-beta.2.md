# KeyOops 0.2.1 beta 2 (build 7)

Quit KeyOops, open **KeyOops-build-7-macOS-universal.dmg**, and drag KeyOops into Applications. Choose Replace and launch the installed copy. The app supports macOS 14 or later on Intel and Apple silicon.

This beta is ad-hoc signed and has no Apple notarization. See the [first-launch guide](https://github.com/bilaklada/KeyOops/blob/v0.2.1-beta.2/docs/releases/0.2.0-beta.1.md). Enable Accessibility and Input Monitoring for /Applications/KeyOops.app, then choose Suggest or Automatic in its menu.

## What changed

- KeyOops can discover editable combo boxes, editable groups, and text inside embedded web documents. It can request the accessibility tree from Chromium and Electron hosts that expose it on demand.
- When a field cannot be used, the KeyOops menu reports the missing capability without storing its text or URL.
- Corrections remain tied to the focused field and document. KeyOops skips secure input and recognized terminal and source-editor controls.

The automated correction, undo and isolation checks passed. Five Chrome fixtures passed focus and caret checks. Live correction in Gmail and VS Code/Codex remains unverified because the host verifier lacked macOS Accessibility permission.
